# 生成提示与身份一致性

## 基准角色图

先制作一张视觉基准图，要求：

- 单一完整角色、正面或自然三分之四视角、全身居中。
- 轮廓紧凑，在 `192×208` 的显示尺寸仍能辨认。
- 纯色键控背景，无文字、界面、场景、地面阴影或漂浮特效。
- 明确记录脸型、发型、服装、配色、材质、标志性配饰和身体比例。

人物照片风格需要保留可识别特征，但不要逐行重新解释人物长相；每一行动画都附上同一张基准图，并把它声明为唯一身份来源。

## 逐行提示词结构

每个动画行提示词至少说明：

1. 行状态与准确帧数。
2. 从左到右的动作节奏。
3. 必须保持不变的身份特征。
4. 纯色背景、独立姿态、间距和安全边距。
5. 禁止出现的文字、边框、网格、场景、阴影和分离特效。

示例：

```text
以附带的角色基准图为唯一身份来源，生成一条 8 帧横向动画条。
状态：running-right，角色面向并移动到屏幕右侧。
保持脸型、发型、服装、拳套、配色、写实光照和身体比例一致。
八个姿态从左到右形成连续交替步态，每个姿态完整、互不重叠并留出安全边距。
背景使用指定纯色键控色。不要文字、边框、网格、速度线、灰尘、地面阴影或场景。
```

## 动作语义

- `idle`：轻微呼吸、眨眼、点头；不要混入工作或招手动作。
- `waving`：用肢体姿态表达挥手，不画动作弧线。
- `jumping`：用身体高度表达起跳，不画落地烟尘或影子。
- `failed`：通过表情和身体塌落表达；需要眼泪时应与脸部连接。
- `waiting`：期待用户回应，和普通待机、结果复核明显区分。
- `running`：思考、处理、扫描或专注工作；不要画成奔跑。
- `review`：通过视线、头部或上身姿态表达认真复核。

## 方向动画

先生成并确认四个方向锚点：向上、向右、向下、向左。再基于它们生成两条连续的八帧方向行。

- 眼睛、头部、上身、耳朵、毛发或道具应按角色结构自然跟随。
- 固定脚底或下半身基准，避免整只角色在格内左右漂移。
- 不要旋转整张角色图片来伪造注视方向。
- 相邻 22.5° 姿态的变化量应均匀；四个主方向必须一眼可辨。
