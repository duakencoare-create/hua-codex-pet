# “华”Codex 宠物安装说明

这个分享包包含可直接安装的宠物目录 `sleepy-boxer`。

## 安装

1. 退出 Codex。
2. 将整个 `sleepy-boxer` 文件夹复制到 Codex 的 `pets` 目录：
   - macOS / Linux：`~/.codex/pets/`
   - Windows：`%USERPROFILE%\.codex\pets\`
3. 最终应存在：`~/.codex/pets/sleepy-boxer/pet.json` 和 `spritesheet.png`。
4. 重新打开 Codex，在宠物选择器中选择“华”。

若目标位置已有同名 `sleepy-boxer` 文件夹，请先备份旧文件夹，再用本包替换。

## 包内容

- `sleepy-boxer/pet.json`：宠物名称与版本信息
- `sleepy-boxer/spritesheet.png`：9 行 v1 动画图集
- `validation.json`：打包时的图集校验结果
- `SHA256SUMS.txt`：文件完整性校验值
